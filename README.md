# Divine Lines website

Public marketing, privacy, terms and support website. Application source is not included.

Live: https://imrkr18.github.io/divine-lines-pages/

Buildless HTML, CSS and JavaScript. GitHub Pages publishes `main` at the root. Preview with `python3 -m http.server 8765`. No package installation or build step.

Pages: Home, The App, Our Purpose, Privacy, Terms, Support.

The phone and wallpaper compositions are labeled illustrative/design previews, not screenshots of a released app. Store availability is coming soon; replace with verified store links only after launch. Theme names and colors follow the app registry. No testimonials or adoption claims.

Fonts are self-hosted DM Sans and Cormorant Garamond; their licenses are included in assets. No external font requests, trackers, cookies, forms or analytics. Motion respects prefers-reduced-motion. Content remains visible without JavaScript.
